📌 Git Convention

### (1) Branch type
- 기본 브랜치
  - main
    - 배포 및 최종 결과물 브랜치
    - 직접 커밋 ❌
  - dev
    - 개발 통합 브랜치
    - 기능 개발 완료 후 PR을 통해 병합
- 작업 브랜치
  - 새로운 기능 구현
    ```
    feat/기능명/이름
    ```
  - 버그 및 오류 해결
    ```
    fix/버그명/이름
    ```
  - 포맷, 세미콜론 등 (코드 동작 변화 없음)
    ```
    style/기능명/이름
    ```
  - 리팩토링 (기능 변화 없음)
    ```
    refactor/기능명/이름
    ```
  - 포맷, 세미콜론 등 (코드 동작 변화 없음)
    ```
    chore/기능명/이름
    ```

### (2) COMMIT 메시지
- 형식
    ```
    type: 커밋메시지
    ```
- 규칙
    - `:` 앞 공백 없음, 뒤 공백 1칸 필수
    - 커밋 메시지는 한글 통일
    ```
    // 예시
    feat: 로그인 UI 구현 
    fix: 로그인 오류 수정 
    docs: 협업 컨벤션 문서 추가
    ```

### (3) Pull Request
- PR 생성 규칙
  - dev 브랜치로만 PR 생성
- PR 내용
  - 작업 내용 요약
  - UI 작성 시 스크린샷 첨부
- 병합 규칙
  - 충돌 발생 시 PR 생성자가 해결
  - 최소 1명 리뷰 후 병합
